Política de privacidad

Última actualización: 28 de septiembre de 2026.

Qué información se procesa y para qué

Cuando la persona abre Papel notarial desde un Google Doc, la extensión lee la dirección y el título de esa pestaña para identificar el documento. Con autorización OAuth de esa persona, consulta el documento mediante la API oficial de Google Docs. El contenido puede incluir datos personales que la persona haya escrito en él. La extensión usa ese contenido únicamente para aplicar el formato solicitado y, si se elige imprimir, preparar la vista de impresión.

Dónde se procesa y con quién se comparte

El contenido del documento y el token OAuth se usan en el navegador para comunicarse directamente, mediante HTTPS, con la API de Google Docs. Google recibe las solicitudes necesarias para prestar esa función y las procesa conforme a sus propias condiciones y políticas. Anthony Rodriguez y los desarrolladores de Papel notarial no reciben una copia del documento ni operan un servidor propio que reciba su contenido. La extensión no vende datos ni los comparte con terceros para publicidad, analítica o fines ajenos a la función descrita.

El token OAuth se obtiene mediante Chrome Identity y se usa para autorizar las solicitudes a Google. La extensión no lo guarda en su almacenamiento propio ni lo envía a los desarrolladores. La autorización puede revocarse desde la configuración de seguridad de la cuenta de Google.

Almacenamiento y eliminación

La extensión guarda localmente en Chrome la aceptación de este aviso. Para imprimir, mantiene temporalmente el texto necesario en el almacenamiento de sesión del navegador y lo elimina cuando se abre la vista de impresión. No mantiene una base de datos propia ni conserva un historial de documentos. Al cerrar la sesión del navegador, Chrome elimina el almacenamiento de sesión; al desinstalar la extensión, se elimina también su almacenamiento local.

Alcance de la herramienta

Papel notarial es una herramienta auxiliar de formato e impresión. No brinda asesoramiento jurídico o notarial ni verifica la exactitud, integridad, validez, autenticidad o suficiencia legal del documento. La extensión tampoco controla la impresora, el papel cargado ni el resultado físico. Antes de firmar, presentar, protocolizar o usar un documento, la persona usuaria y el estudio deben revisar el texto, el formato, la vista previa, la orientación, la impresión a doble cara y la correspondencia con el papel utilizado. Conviene realizar una prueba de impresión cuando el resultado sea importante.

La herramienta se ofrece sin garantía de disponibilidad continua ni de que el resultado sea apto para un trámite o impresora particular, en la medida permitida por la ley. Esta información no pretende excluir derechos ni responsabilidades que legalmente no puedan excluirse o limitarse.

Uso limitado de datos de Google

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de Datos de Usuario de los Servicios API de Google, incluidos sus requisitos de Uso Limitado.
